FIRST OMS 땡라이브 비상운영 v3 - 가입폼 연동

[PC에서 실행]
1. Node.js가 설치되어 있어야 합니다.
2. Windows: 실행하기.bat 더블클릭
   Mac: 실행하기.command 실행
3. 브라우저에서 http://localhost:3000 접속
4. 고객 가입폼: http://localhost:3000/join.html

[실제 카카오채널 링크로 사용]
- 이 폴더를 가비아 서버에 업로드하고 server.js가 실행되는 Node 호스팅/서버에 배포해야 합니다.
- 공개주소 예: https://도메인/join.html
- 일반 웹호스팅이 PHP만 지원하면 이 Node 서버는 실행되지 않으므로 별도 서버 또는 PHP API 변환이 필요합니다.

[추가 기능]
- 가입폼 제출 → 고객정보 DB 자동 반영
- 5초마다 고객정보 자동 동기화
- 정산실에 이름/연락처/주소 자동 표시
- 택배 파일에 고객정보 자동 반영
- 고객정보 엑셀 저장
- 관리자 수기 고객추가/수정
- 닉네임 또는 전화번호가 같으면 중복 대신 정보 업데이트
