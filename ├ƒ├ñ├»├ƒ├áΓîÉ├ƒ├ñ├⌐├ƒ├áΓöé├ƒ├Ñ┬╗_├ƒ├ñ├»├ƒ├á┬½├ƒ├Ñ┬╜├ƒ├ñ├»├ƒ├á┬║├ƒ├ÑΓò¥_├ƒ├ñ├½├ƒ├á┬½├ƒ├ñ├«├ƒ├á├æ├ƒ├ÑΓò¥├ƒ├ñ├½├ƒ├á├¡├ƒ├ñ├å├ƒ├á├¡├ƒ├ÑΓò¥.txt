v4.8 오늘 운영 수정

- 방송 시작 버튼: 테스트 주문/정산/문자대기 초기화
- 고객 닉네임과 고객DB 일치 시 이름/연락처/주소 자동연결
- 정산실 입금/미입금/보류 수기 선택
- 입금 완료 고객 문자 대기실 이동
- 정산서 상세 팝업
- 정산서만 별도 창으로 인쇄
- 문자 대기실 고객별 정산서 상세보기
- 문자전송 버튼 → 정산서/수신번호/문자내용 최종 팝업 확인 → 실제 SOLAPI API 전송
- 선택전송/일괄전송도 저장된 전화번호로 직접 API 발송
- 문자사이트로 이동하거나 번호를 복사할 필요 없음
- Render 환경변수 SOLAPI_API_KEY / SOLAPI_API_SECRET / SOLAPI_SENDER 사용

주의:
실제 문자발송은 SOLAPI 발신번호 승인, 잔액, 발송한도가 정상이어야 성공합니다.
