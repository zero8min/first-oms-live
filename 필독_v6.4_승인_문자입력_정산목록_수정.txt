땡라이브서버 v6.4 수정내용

1. 최고관리자 거래처 승인/대기/정지 버튼 수정
- 클릭 즉시 처리중 표시
- 성공/실패 메시지 표시
- 처리 후 계정목록 자동 새로고침
- 세션 쿠키를 명시적으로 포함하여 승인 API 호출

2. 문자내용 입력칸 수정
- 입력 중 다른 화면 렌더링 때문에 내용이 사라지지 않도록 보호
- 입력 즉시 브라우저 임시저장
- 저장 버튼을 누르면 정식 설정으로 저장
- 새로고침 전 미저장 문구도 복구

3. 정산서 화면 변경
- 정산서 이미지를 처음부터 전부 펼치지 않고 고객 목록으로 표시
- 닉네임, 이름, 연락처, 주소, 합계, 입금상태 표시
- 상세 버튼을 누르면 정산서 이미지 형태 팝업 표시
- 팝업에서 수정, 인쇄, 닫기 가능
- 중요 정산서 별표 표시 가능
- 닉네임 가나다순 정렬

4. 입금명세 업로드 개선
- 카카오뱅크 양식의 '내용' 열을 입금자명으로 인식
- 모든 시트에서 거래일시/거래금액/내용 헤더를 탐색
- 출금 내역은 제외하고 입금만 등록

주의
- 기존 Persistent Disk의 data 폴더는 삭제하거나 덮어쓰지 마세요.
- 배포할 때 서버 소스만 교체하고 data 폴더는 기존 디스크 자료를 유지하세요.
