포함된 현재 자료
- 주문: 632건
- 고객: 133명
- 입금내역: 0건
- 계좌/문자 설정 포함

첫 실행
1. 기존 브라우저 저장자료가 있으면 기존 자료를 우선 사용합니다.
2. 저장자료가 없는 새 브라우저에서는 data/initial-backup.json을 자동 복원합니다.
3. 고객DB는 data/customers.json에도 포함되어 있습니다.

솔라피 연결
- 대시보드의 '솔라피 API 입력·연결' 또는 '솔라피 연결' 카드를 누르세요.
- API Key, API Secret, 승인 발신번호를 입력하고 'API 입력값 저장·연결'을 누르세요.
- 카카오 알림톡은 PF ID와 승인 템플릿 ID도 입력해야 합니다.
- API Secret은 화면에 다시 표시되지 않습니다.

주의
Render 재배포에도 API와 새 고객자료를 보존하려면 Persistent Disk 또는 Render Environment 설정을 함께 사용하세요.
