FIRST OMS 땡라이브서버 v6.8 수정내용

1. 입금대조
- 일반 XLSX/XLS/CSV 입금명세 자동 인식
- 일반 방식으로 열리지 않는 암호 보호 XLSX는 암호 입력창 표시
- 입력한 암호로 파일을 브라우저 안에서 복호화 후 입금내역 등록
- 모든 시트에서 거래일시/거래금액/내용(입금자) 헤더 자동 탐색
- 입금액이 양수인 행만 등록하고 정산서의 고객명/닉네임/금액과 자동 대조
- 암호는 저장하거나 서버로 전송하지 않음

2. 고객정보 깨진 문양
- 고객명/닉네임/연락처/주소의 대체문자(�)와 연속 물음표를 화면에서 제거
- 서버 고객폼 자료를 불러올 때 정리 후 다시 고객DB 매칭
- 비활성 고객은 자동매칭 대상에서 제외
- 깨진 문자 일부가 섞여 있어도 남은 정상 닉네임으로 단일 고객을 찾으면 연결

3. 중요 별표
- 빈 별(☆) 클릭 시 채워진 별(★)로 변경
- 중요 체크 시 금색 버튼과 행 배경으로 즉시 표시
- 다시 누르면 중요 체크 해제
- 저장 후 새로고침해도 상태 유지

주의
- 기존 Render Persistent Disk의 data 폴더는 삭제하지 마세요.
- 암호 파일 기능은 관리자 브라우저가 인터넷에 연결되어 있어야 복호화 모듈을 불러올 수 있습니다.
- 이미 원본 글자가 완전히 손상되어 대체문자로 저장된 경우 해당 글자는 기술적으로 복원할 수 없으므로 고객정보 수정에서 원문을 다시 저장해야 합니다.
