가입폼은 join.html을 직접 더블클릭하면 고객DB 자동연동이 되지 않습니다.

맥 실행 순서
1. ZIP 압축 해제
2. 실행하기.command 더블클릭
3. 브라우저에서 http://localhost:3000/join.html 확인
4. '서버 연결 확인' 버튼 → '서버 연결이 정상입니다' 확인
5. 성함/닉네임/연락처/주소 입력
6. 개인정보 동의 체크
7. 가입 완료
8. 관리자 http://localhost:3000 → 고객정보 메뉴에서 등록 확인

주소검색이 인터넷 환경에서 막히면 기본주소를 직접 입력해도 가입 완료됩니다.
