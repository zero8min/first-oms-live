FIRST OMS / 땡라이브 v7.47.1 로그인·다른PC 데이터 보존 수정

핵심 수정
1. 로그인하면 브라우저 localStorage가 아니라 해당 거래처의 서버 저장 데이터를 우선 불러옵니다.
2. 새 컴퓨터에서 localStorage가 비어 있어도 서버 고객DB/주문/입금/설정을 불러옵니다.
3. 서버 상태 조회가 실패했을 때 initial-backup/localStorage 내용을 자동으로 서버에 덮어쓰지 않습니다.
4. 서버 연결 실패 중에는 로컬 캐시는 화면 확인용으로만 사용하고 서버 저장을 차단합니다.
5. 다른 컴퓨터에서 더 최신 데이터가 저장된 경우 오래된 화면의 저장 요청은 409로 차단하고 최신 서버 상태를 다시 불러옵니다.
6. 고객DB 실시간 동기화 시 전체 state를 다시 POST하지 않아 오래된 주문/입금 상태가 덮일 위험을 줄였습니다.
7. 서버 연결이 돌아오면 서버 원본을 다시 불러옵니다.

중요
- Render Persistent Disk의 data 폴더는 삭제/덮어쓰기 금지.
- 같은 거래처 계정으로 로그인하면 기기와 관계없이 서버 원본을 불러오는 구조입니다.
- 브라우저 캐시는 보조용이며 서버 원본보다 우선하지 않습니다.
