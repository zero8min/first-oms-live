FIRST OMS / 땡라이브 v7.49

[이번 수정]
1) 화면 자동이동/스크롤 튐 방지
- 고객DB SSE 자동 전체렌더링 종료
- 서버값이 실제 변경된 경우에만 현재 화면 최소 갱신
- 스크롤/포커스/선택 위치 복원
- 택배실도 상태 변경시에만 화면 갱신

2) 택배팀 무로그인 포장
- /packing.html (기본 FIRST-0001)
- 최초 1회 포장자 이름 입력 -> 기기 localStorage 저장
- 다음 접속부터 이름 자동 표시 / 포장자 변경 가능
- 다음 미완료 주문 자동 표시
- [다 넣었어요] -> 관리자 즉시 포장완료 저장
- 포장완료 후 송장스캔 전에는 다음 주문 진행 불가

3) 송장 바코드 필수
- 카메라 스캔
- 기본 택배사 CJ대한통운
- 현재 고객에게 이미 발부/등록된 송장과 다르면 완료 차단
- 스캔 송장이 다른 고객에게 이미 등록된 번호면 완료 차단
- 정상스캔 -> 송장번호/포장자/포장시간/택배사/송장스캔시간 저장 -> 출고준비완료

중요: 시스템에 '고객별 사전 송장번호 매핑'이 없는 완전히 새로운 송장은
다른 고객 송장인지 외부 CJ 시스템만으로 역조회할 수 없습니다.
이 경우 시스템 내부에서 다른 고객에게 이미 등록된 송장 중복 여부를 우선 검증합니다.
CJ 자동발부 또는 발급 송장파일 업로드로 고객별 송장번호가 미리 들어가 있으면
현재 고객 송장번호와 1:1 완전 비교하여 잘못된 송장을 차단합니다.

4) 배송문자
- 정상 송장 최초 확인 시 1회 자동 발송
- 새로고침/동일송장 재스캔 시 중복 발송 금지
- 문자 실패해도 포장/송장 완료는 유지
- 관리자 택배실에 발송실패 표시 + 재발송 버튼

5) 관리자 택배실 실시간 정보
- 포장대기 / 포장완료 / 출고준비완료
- 포장자 / 포장완료시간 / 택배사 / 송장번호 / 송장스캔시간 / 배송문자 상태
