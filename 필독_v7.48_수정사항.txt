FIRST OMS 땡라이브 v7.48 수정사항

1. 백그라운드 동기화 시 화면/스크롤이 멋대로 움직이지 않도록 변경사항 있을 때만 최소 갱신
2. 방송일/정산서/날짜별 기록실 날짜칸 클릭 시 달력 열기 + 달력 버튼
3. 입금대조: 본명/닉네임/괄호 안 이름/공백·기호 조합 인식, 금액 숫자 정규화, 입금 1건=정산 1건
4. 날짜별 기록실 날짜 변경 즉시 조회
5. 택배실: 첫 장 품번별 총 수량표, 누락건 빨간 구역, 누락건 등록/삭제, 고객별 포장리스트 후속 출력
   - 김치 전용 리스트 버튼: 품명에 김치/깍두기/총각/열무/배추/파김치/갓김치/백김치/동치미/겉절이 포함 시 자동 분리
6. 품목이 12개를 넘어 정산서가 여러 장이면 배송비와 전체 총 결제금액은 마지막 장에만 표시/청구
7. 고객DB 연락처 자리수/형식 오류 자동 강조
8. 택배 엑셀 주소 칸에서 우편번호 제거, 우편번호는 별도 컬럼 유지
9. 방송 전 문자 문구/누락건 등 state 서버 자동저장 강화, 페이지 종료 직전 서버 저장 시도

주의: 기존 data 폴더/고객DB/솔라피 설정은 삭제하지 말 것.
