땡라이브서버 v7.12 데이터보존·택배실 추가 기능

1. 기준 소스는 v7.11입니다. 로그인/권한/거래처 분리 기능은 유지했습니다.
2. FIRST-0001 현재 백업 데이터가 data/tenants/FIRST-0001에 포함되어 있습니다.
   - 주문 1,596건
   - 고객 137명
   - 입금내역 68건
3. 서버 상태 저장은 기존 배열을 지우지 않고 ID 기준으로 보호 병합합니다.
4. 추가 기능
   - 택배사 API 설정값 거래처별 저장
   - 택배실 닉네임(이름), 주소, 연락처, 송장번호 표시
   - 정산서 보기, 고객 상세, 고객별 CS 기록
   - 청구금액/입금액 분리 표시
   - 송장번호 저장, 송장 발부 상태 분리
   - 출고 안내 문자 버튼
   - 10만원 이상 송장 출력 2장
5. 실제 택배사 송장 자동발행 API 호출은 해당 택배사의 운영 API 문서, 계약 고객코드와 인증값이 필요합니다. 현재 버전은 안전한 등록·보관 및 화면 연결까지 추가했습니다.
