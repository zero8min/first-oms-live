땡라이브서버 v7.5 — 거래처 완전 분리 / 최고관리자 거래처 전환

1. 현재 공용 데이터는 최초 1회 FIRST-0001(땡라이브) 폴더로 안전 이전됩니다.
2. 신규 거래처는 고객·정산·입금·택배·문자기록이 모두 0건인 빈 저장소로 생성됩니다.
3. 거래처별 저장 위치:
   /data/tenants/FIRST-0001/
   /data/tenants/FIRST-0002/
4. 솔라피 API Key/Secret/발신번호/카카오 설정은 거래처별 solapi-settings.json에 따로 저장됩니다.
   다른 거래처의 설정이나 Render 공용 SOLAPI 환경변수를 거래처 계정이 자동 공유하지 않습니다.
5. 최고관리자는 superadmin.html에서 '거래처 페이지 열기'를 누르면 해당 거래처로 전환됩니다.
   정산실 상단에 '최고관리자 대리접속 중 / 현재 거래처' 안내가 표시됩니다.
6. 일반 거래처 계정은 세션에 연결된 자기 tenantCode만 사용하며 URL을 바꿔 다른 거래처 자료에 접근할 수 없습니다.
7. 계정 목록(accounts.json)과 각 거래처 폴더는 Persistent Disk에 보존됩니다.

주의: /opt/render/project/src/data 폴더는 삭제하거나 GitHub 파일로 덮어쓰지 마세요.
